Welcome to GuildThing Sync

This app syncs your guild's roster cache from World of Warcraft to your guild's GuildThing site — automatically, for as long as this window is open.

You'll need: your WoW installation (the folder the game lives in) and an API key from the site (Admin → API keys on your guild's page).

Where is WoW installed?

The folder that contains the version folders, e.g. _classic_era_.
